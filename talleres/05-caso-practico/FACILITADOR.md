# Facilitador — Módulo 5

Presente el caso ficticio de Escuela Bosque Claro: ordenar observaciones sin nombres para preparar una pauta de acompañamiento. Muestre una opción sin IA y una con IA. Pregunte qué aporta realmente la segunda.

Cada equipo completa “Hoy ocurre…”, “Nos cuesta…” y “Sabríamos que mejora si…”. Después usa el Canvas: problema, grupo, tarea, alternativa sin IA, herramienta, datos permitidos, datos prohibidos, revisión, evidencia, indicador y criterio de detención.

Use el semáforo de privacidad, exactitud, sesgo, dependencia, accesibilidad y carga de trabajo. Todo rojo exige rediseño. Una tarea que decide sobre una persona no pasa a una prueba. Cierre invitando a convertir el caso en un prompt verificable o una microacción.
