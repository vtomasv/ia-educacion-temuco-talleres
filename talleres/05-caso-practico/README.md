# Taller 5 — Caso de uso priorizado

**Problema:** Una idea interesante puede ser demasiado amplia, riesgosa o imposible de evaluar.

**Resultado:** El equipo diseña un caso acotado para un desafío real, usando información ficticia, con evidencia, responsable, riesgo y reversibilidad.

**Duración:** 60 minutos, 14:30–15:30. **Previo:** mapa de oportunidades. **No intenta enseñar:** implementación institucional completa ni compra de software.

**Herramienta principal:** Canvas de caso de uso y matriz de riesgos. **Alternativa:** caso modelado por facilitador. **Modelo:** no es necesario; demo opcional de NotebookLM/Diffit con documento público. **Producto:** caso priorizado. **Éxito:** el Canvas responde qué, para quién, con qué evidencia, qué no se ingresa y quién decide.
