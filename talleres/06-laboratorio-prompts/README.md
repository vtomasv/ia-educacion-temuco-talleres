# Taller 6 — Laboratorio de prompts

**Problema:** “Mejora esta planificación” produce resultados genéricos porque omite propósito, contexto, criterios y verificación.

**Resultado:** El participante mejora iterativamente seis versiones de un prompt y conserva una plantilla reutilizable.

**Duración:** 50 minutos, 15:30–16:20. **Previo:** caso de uso. **No intenta enseñar:** ingeniería de prompts como disciplina aislada ni trucos mágicos.

**Herramienta principal:** modelo local o asistente web con documento ficticio. **Alternativa:** respuestas preparadas. **Modelo:** Qwen3 1.7B/0.6B. **Producto:** prompt probado y protocolo de verificación. **Éxito:** la versión final especifica propósito, contexto, información, tarea, audiencia, criterios, restricciones, formato y verificación.
