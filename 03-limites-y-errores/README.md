# Taller 3 — Cuando la respuesta parece correcta

**Problema:** La fluidez de una respuesta puede hacer que un equipo la comparta sin comprobarla.

**Resultado:** El participante clasifica respuestas ficticias como verificables, dudosas o incorrectas, identifica el tipo de error y elige una fuente o acción de comprobación.

**Duración:** 60 minutos, 11:00–12:00. **Previo:** Taller 2. **No intenta enseñar:** detección automática perfecta ni una lista exhaustiva de riesgos.

**Herramienta principal:** navegador con fuentes oficiales y respuestas preparadas. **Alternativa:** modelo local con preguntas ficticias. **Modelo:** Qwen3 1.7B/0.6B. **Hardware:** proyector y fichas. **Producto:** matriz de criterio directivo. **Éxito:** justificar cuatro clasificaciones y definir una acción de verificación.

**Riesgos:** presentar errores como rarezas, usar nombres reales, ridiculizar respuestas. **Plan B:** sobre de casos y fuentes impresas.
