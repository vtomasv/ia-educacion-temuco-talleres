# Materiales — Taller 3

Prepare cuatro sobres, cada uno con un caso ficticio, una respuesta de modelo, una fuente oficial o nota que indique que no existe, y la matriz de verificación. Use fuentes públicas; no cargue documentos confidenciales. Colores de clasificación: verde = verificable, amarillo = dudoso, rojo = incorrecto.

Prompt opcional: `Responde sobre este escenario ficticio. Si no tienes evidencia suficiente, dilo. No inventes fuentes ni nombres. Pregunta si la consulta es ambigua.`
