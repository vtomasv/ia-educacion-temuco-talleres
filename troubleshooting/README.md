# Solución de problemas

| Problema | Plan A | Plan B | Plan C |
| --- | --- | --- | --- |
| No hay internet | Modelo local preparado | Proyección facilitador | Respuestas impresas |
| LM Studio no abre | Revisar compatibilidad | Ollama facilitador | Tarjetas de predicción |
| Modelo responde lento | Reducir contexto/modelo | Trabajar por parejas | Ficha de comparación |
| No hay cuenta web | Documento público local | Demo facilitador | Caso impreso |
| El modelo inventa una fuente | Marcar y verificar | Comparar respuesta preparada | Protocolo de verificación |
| Se pegan datos reales | Detener y retirar | Sustituir por dataset ficticio | Explicar sin culpar |
| El sitio no carga | Abrir `site/index.html` | Usar PDF/fichas | Guía oral |
| Falta tiempo | Priorizar producto y cierre | Reducir plenaria | Microacción en papel |

Si la tecnología falla, se conserva el aprendizaje esperado aunque cambie el medio. Ningún bloque depende de una única plataforma.
