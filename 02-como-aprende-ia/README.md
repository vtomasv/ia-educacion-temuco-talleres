# Taller 2 — ¿Cómo aprende una IA?

**Problema:** Explicaciones técnicas tempranas pueden producir una ilusión de comprensión o atribuir intención humana a un modelo.

**Resultado:** El participante explica la cadena texto→tokens→contexto→probabilidades→siguiente token→respuesta y comprende que probabilidad no equivale a verdad.

**Duración:** 75 minutos, 09:15–10:30. **Previo:** ninguno. **No intenta enseñar:** matemáticas de transformers, entrenamiento avanzado ni programación.

**Herramienta principal:** LM Studio preparado con Qwen3 1.7B cuantizado. **Alternativa:** Ollama del facilitador. **Modelo:** Qwen3 1.7B; Qwen3 0.6B para Perfil A. **Hardware:** proyección y equipo local; 8–16 GB si se prueba por parejas. **Producto:** mapa causal y una frase de liderazgo. **Éxito:** explicar dos efectos del contexto y una razón para verificar.

**Riesgos:** confundir simulación manual con funcionamiento completo, sobrecargar con términos, convertir el bloque en demo. **Plan B:** tarjetas de predicción y respuestas impresas.
