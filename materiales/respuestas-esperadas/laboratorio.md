# Respuestas esperadas para el laboratorio

Las respuestas pueden variar. La versión inicial suele ser genérica y puede cambiar el objetivo o inventar detalles. Las versiones con propósito y contexto deberían mantener la diferencia entre objetivo, actividad y evidencia. La versión con criterios debería producir observaciones más comparables. La versión con formato debería facilitar revisión. La versión con verificación debería separar texto e inferencia, pero aun así requiere lectura humana.

No existe una única respuesta correcta. El facilitador debe evaluar el proceso de comparación y la justificación, no premiar el texto más largo.
