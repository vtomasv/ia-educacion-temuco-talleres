# Kit offline

## Qué incluye

El kit offline se puede distribuir antes de facilitar en una memoria o carpeta local. Incluye el sitio estático, guías, prompts, datasets ficticios, respuestas esperadas, instrumentos de evaluación, checklist y planes B. No incluye pesos de modelos: su tamaño, licencia y compatibilidad cambian, por lo que el facilitador debe descargarlos previamente según el equipo y conservar la tarjeta de licencia.

## Preparación

1. Copie el contenido del repositorio a una carpeta local.
2. Abra `site/index.html` en un navegador o sirva `site/` con cualquier servidor estático.
3. Pruebe enlaces a `talleres/`, `materiales/` y `setup/` desde la copia que utilizará.
4. Prepare LM Studio u Ollama en al menos un equipo facilitador.
5. Apague internet y compruebe que el modelo responde con un prompt ficticio.
6. Imprima las fichas de casos, laboratorio de prompts, privacidad, evaluación y microacción que necesite.

## Límite

El modo offline reduce dependencia de conectividad, pero no garantiza por sí solo privacidad, exactitud ni cumplimiento. El uso de datos personales queda prohibido en todos los modos.
