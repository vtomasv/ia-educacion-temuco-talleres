# Arquitectura pedagógica

## Principio de diseño

La secuencia sigue el ciclo **experiencia → observación → explicación → aplicación → reflexión → transferencia**. El facilitador no comienza por una definición técnica; primero hace visible un fenómeno y pregunta qué evidencia lo sostiene. La teoría llega como una explicación útil para interpretar la experiencia.

## Progresión conceptual

Los conceptos se introducen en este orden: IA, modelo, modelo de lenguaje, modelo local, contexto, prompt, verificación, RAG y agentes. Cada concepto aparece con definición simple, ejemplo, experiencia y consecuencia educativa. La explicación técnica queda en una capa “Saber más” y nunca es requisito para completar el trabajo.

## Evidencias de aprendizaje

| Competencia observable | Evidencia | Criterio de logro |
| --- | --- | --- |
| Comprender cómo produce texto un modelo | Mapa de predicción y contexto | Explica que una salida probable no es automáticamente verdadera |
| Reconocer límites | Clasificación de cuatro respuestas ficticias | Marca al menos tres casos con justificación y fuente de comprobación |
| Elegir un uso educativo pertinente | Mapa de oportunidades | Distingue tareas mecánicas, tareas de juicio profesional y tareas no delegables |
| Formular instrucciones útiles | Seis versiones de un prompt | Incluye propósito, contexto, criterios, formato y verificación |
| Resguardar información | Checklist de privacidad | Rechaza datos personales y propone una alternativa ficticia o local |
| Transferir a la institución | Microacción de cuatro semanas | Define grupo, responsable, evidencia, indicador y límite reversible |

## Andamiajes

El material usa cuatro niveles de apoyo. En primer lugar, tarjetas con ejemplos ya trabajados para quienes necesitan reducir carga cognitiva. En segundo lugar, plantillas incompletas para completar en parejas. En tercer lugar, una capa técnica optativa para participantes con mayor interés. En cuarto lugar, un Plan C manual para que el aprendizaje continúe aun cuando fallen la conectividad, la cuenta o la instalación.

## Evaluación

El pretest y postest contienen ocho preguntas equivalentes, no idénticas: dos de comprensión, dos de identificación de error, una de elección de herramienta, una de privacidad, una de calidad de instrucciones y una de necesidad de verificación. Se reportará aprendizaje observable del grupo, no satisfacción como sustituto de aprendizaje. La satisfacción se recogerá aparte y no se mezclará con el resultado cognitivo.

## Privacidad por diseño

Todo documento, encuesta, observación, acta, proyecto o comunicación del kit es ficticio. El sitio mostrará de forma permanente: **“Durante este taller no utilizaremos información personal ni sensible de estudiantes, familias o funcionarios.”** A la fecha de consulta, la Ley 19.628 se mantiene como norma general vigente hasta el 30 de noviembre de 2026 y la Ley 21.719 tiene vigencia diferida al 1 de diciembre de 2026; el material no constituye asesoría jurídica y exige revisión del sostenedor antes de cualquier piloto institucional.
