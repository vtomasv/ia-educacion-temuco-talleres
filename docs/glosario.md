# Glosario docente

| Concepto | Definición breve |
| --- | --- |
| IA | Sistemas que realizan tareas asociadas con capacidades humanas, como reconocer patrones o producir lenguaje. |
| Machine learning | Método en que un sistema aprende regularidades desde datos para producir predicciones o decisiones. |
| Red neuronal | Modelo computacional compuesto por capas de operaciones que transforman representaciones. |
| IA generativa | Sistemas que producen texto, imágenes, audio u otros contenidos a partir de una entrada. |
| LLM | Modelo de lenguaje de gran escala que calcula continuaciones de texto según patrones aprendidos. |
| Modelo | Representación aprendida que transforma entradas en predicciones o salidas. |
| Modelo local | Modelo cuya inferencia se ejecuta en el equipo, sin depender necesariamente de una nube. |
| Nube | Servidores remotos accesibles por internet donde se procesan datos y aplicaciones. |
| Token | Unidad de texto que el modelo procesa: palabra, parte de palabra o signo. |
| Contexto | Información que acompaña una instrucción y cambia las continuaciones plausibles. |
| Prompt | Instrucción o conjunto de datos que orienta una tarea, formato y criterios. |
| Alucinación | Contenido inventado o no sustentado que se presenta como confiable. |
| Embedding | Representación numérica que ubica textos según relaciones de significado aproximadas. |
| RAG | Recuperación de documentos pertinentes antes de generar una respuesta. |
| Agente | Sistema que combina modelo con herramientas, memoria o pasos para alcanzar una meta. |
| Multimodal | Capaz de recibir o producir más de un tipo de información, como texto e imagen. |
| Cuantización | Reducción de precisión numérica para disminuir memoria y facilitar ejecución local. |
