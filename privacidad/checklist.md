# Checklist de privacidad por diseño

| Pregunta | Sí / No | Acción si es “No” |
| --- | --- | --- |
| ¿El material es ficticio, público o está autorizado? | | Detenerse y reemplazar |
| ¿Se eliminaron nombres, RUT, correos, teléfonos y ubicaciones? | | Anonimizar |
| ¿Se eliminaron diagnósticos, salud, necesidades, sanciones y calificaciones? | | No ingresar |
| ¿Se sabe dónde se procesa y cuánto se conserva? | | Consultar al sostenedor |
| ¿La tarea podría hacerse sin IA o con un modelo local? | | Comparar alternativa |
| ¿Existe revisión humana? | | Nombrar responsable |
| ¿La salida influye en una decisión sobre una persona? | | No automatizar |

> **Durante este taller no utilizaremos información personal ni sensible de estudiantes, familias o funcionarios.**

La normativa cambia y este material no constituye asesoría jurídica. A la fecha de consulta, revisar Ley 19.628 vigente y preparar la transición a Ley 21.719, cuya vigencia general figura diferida al 1 de diciembre de 2026.
